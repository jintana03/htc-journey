คู่มือการใช้งาน

เว็บไซต์ช่วยแปลงบทความและรูปภาพเป็น HTML ตาม Template ของ HTC Journey พร้อม Compress รูปภาพได้ในขั้นตอนเดียว

นอกจากนี้ยังสามารถปรับขนาด Column ของรูปภาพ เช่น col-md-6 และ col-md-4 ได้โดยตรง โดยไม่ต้อง Inspect หรือเข้าไปแก้ไข Code เอง ช่วยลดขั้นตอนในการจัดวางรูปภาพและทำให้อัปเดตบทความได้สะดวกมากขึ้นค่ะ

  1. เลือกโฟลเดอร์ลากโฟลเดอร์ที่มีบทความ DOCX, HTML หรือ TXT และรูปภาพประกอบ มาวางในช่อง INPUT FOLDER หรือคลิกเพื่อเลือกจากเครื่อง
  2. ตรวจสอบผลลัพธ์ตรวจจำนวนภาพ ลำดับภาพ HTML CODE และ LIVE HTML PREVIEW
  3. นำไปใช้งานกด “คัดลอกโค้ด” หรือ “ส่งออกแพ็กเกจ ZIP” เพื่อนำรูปที่ Compress ไปใช้ต่อได้เลย
รูปแบบภาพ: ภาพแรก 1400 × 700 px · ภาพถัดไปกว้าง 1000 px · Cover 1200 × 625 px ต้องตัดเอง
